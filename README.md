# 🤖 행렬과 인공지능

**2026 수학–정보 융합 프로젝트(기초)** · 당곡고등학교 AI중점학교

> 인공지능은 세상을 어떻게 볼까? 답은 하나 — **행렬로 봅니다.**

고등학교 수학의 행렬·역행렬·일차변환이 인공지능 안에서 실제로 어떻게 쓰이는지,
웹앱으로 관찰하고 파이썬으로 직접 구현하는 수업 자료입니다.

---

## 수업의 뼈대

```
역행렬로 연립방정식을 한 번에 푼다
        ↓
데이터가 많아지면 한 번에 못 푼다   (최소제곱법 = 선형회귀)
        ↓
비선형이면 아예 공식 해가 없다     → 400번 반복해서 조금씩 찾아간다 = 학습
```

## 90분 수업 구성

웹앱(개념) → 코랩(구현) 을 세 번 교차합니다.

| 시간 | 도구 | 내용 |
|---|---|---|
| 0~12 | 웹앱 탭0 | 기저벡터·행렬식 — 격자 붕괴 시연 |
| 12~35 | 코랩 | `my_det`, `my_inv` 직접 구현 ★ |
| 35~45 | 웹앱 탭3 | 연립방정식 세 경우 |
| 45~60 | 코랩 | 오리와 양 → 선형회귀 🌉 |
| 60~70 | 웹앱 탭5 | 커널 필터 |
| 70~90 | 코랩 | 신경망 학습 + **W 시각화** ★★ |

나머지 내용(커널 구현, CNN, 데이터 증강, 힐 암호 등)은 심화 탐구 시간으로 이월합니다.

## 웹앱 탭 구성

| 탭 | 내용 |
|---|---|
| 0. 기저벡터와 행렬식 | 슬라이더로 격자 변형 · det = 넓이 배율 |
| 1. 역행렬 계산기 | det 계산 · 역행렬 존재 조건 |
| 2. 일차변환 실험실 | 회전·대칭·닮음·전단 프리셋 |
| 3. 연립일차방정식 | 두 직선 그래프 · det=0 판정 |
| 4. 이미지 변환 | 사진에 2×2 행렬 적용 |
| 5. 커널 필터 | 3×3 필터 실시간 조작 |
| 6. CNN 단계 체험 | 합성곱 → ReLU → 풀링 |
| 7. 행렬 암호 | 힐 암호 · 역행렬로 열쇠 뚫기 |

## 실행

### 웹앱 (로컬)
```bash
pip install -r requirements.txt
streamlit run app.py
```

### 웹앱 (배포)
Streamlit Community Cloud에 이 저장소를 연결하면 자동 배포됩니다.
자세한 방법은 `04_배포가이드.md` 참고.

### 코랩
노트북을 Google Drive에 올리거나 아래 형식의 링크로 바로 열 수 있습니다.
```
https://colab.research.google.com/github/<계정>/<저장소>/blob/main/행렬과_인공지능.ipynb
```
> `sklearn`, `skimage`는 Colab에 기본 설치되어 있어 별도 설치가 필요 없습니다.
